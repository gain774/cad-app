# CAD App

JWW / AutoCAD / ArchiCAD ライクな操作性を目指した、Web ベースの 2D CAD アプリケーションです。
外部ライブラリに依存しない軽量な描画パイプラインで、要素数が多い図面でも軽快に動作します。

## 特長

- **軽量・高速な描画** — 空間インデックス（グリッドハッシュ）＋ビューポートカリング＋オンデマンド描画。表示範囲の要素だけを描くため、複雑な図面でも重くなりにくい構造です。
- **CAD らしい操作性** — AutoCAD 風コマンドライン、無限キャンバス、ホイールズーム、中/右ドラッグでパン、オブジェクトスナップ（端点・中点・中心・交点・グリッド）。
- **正確な座標入力** — 絶対座標 `100,50`、相対座標 `@50,0`、極座標 `@100<45` に対応。
- **作図ツール** — 線 / 連続線(ポリライン) / 矩形 / 円 / 円弧 / 文字。
- **編集** — 選択（クリック・窓選択・交差選択）、移動、複写、削除、ドラッグ移動、Undo/Redo。
- **レイヤ** — 追加・削除・色変更・表示切替、アクティブレイヤ指定。
- **入出力（互換性）**
  - **DXF 読み込み / 書き出し**（AutoCAD R12 互換のエンティティ集合。AutoCAD・ArchiCAD・Jw_cad との交換用）
  - **SVG 書き出し**
  - **ネイティブ JSON 保存 / 読み込み**（無損失）

## 使い方

```bash
npm install
npm run dev      # 開発サーバ (http://localhost:5173)
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド結果をプレビュー
```

### 基本操作

| 操作 | 方法 |
| --- | --- |
| ツール選択 | 左のツールバー、または `L`(線) `P`(連続線) `R`(矩形) `C`(円) `A`(円弧) `T`(文字) `M`(移動) |
| コマンド入力 | 下部のコマンドラインにキーワードを入力（例: `LINE`, `CIRCLE`, `ZE`=画面いっぱい表示） |
| 座標入力 | コマンドライン: `100,50`（絶対） / `@50,0`（相対） / `@100<45`（極座標） |
| パン | マウス中ボタン or 右ボタンドラッグ |
| ズーム | マウスホイール |
| 選択 | クリック / Shift+クリックで追加 / 空きドラッグで窓選択（右→左は交差選択） |
| 移動・複写 | 対象を選択 → `M` / `CO`（基点→目的点を指定） |
| 削除 | 選択 → `Delete` |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Y` |

## アーキテクチャ

```
src/
  core/
    math/      ベクトル・行列・幾何演算
    model/     エンティティ定義・図面ドキュメント
    spatial/   空間インデックス（グリッドハッシュ）
    commands/  Undo/Redo コマンド履歴
  render/      ビューポート（座標変換）・Canvas レンダラ
  snap/        オブジェクトスナップエンジン
  tools/       作図・編集ツール
  io/          DXF / SVG / JSON 入出力
  ui/          コマンドライン座標パーサ
  Editor.ts    入力処理と各モジュールの統括
  main.ts      UI 配線・エントリポイント
```

### 設計上のポイント

- **エンティティ**は判別可能ユニオン（`line` / `polyline` / `circle` / `arc` / `text`）。境界計算・当たり判定・スナップ点・変換をエンティティ単位の純粋関数で提供。
- **描画**はワールド座標（Y 上向き）とスクリーン座標（Y 下向き）を `Viewport` が変換。レンダラは空間インデックスで可視要素のみ描画。
- **編集**はすべて `History` のコマンド経由で行い、Undo/Redo と空間インデックスの整合性を保証。
